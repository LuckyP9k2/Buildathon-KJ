LOCAL MODEL FILES GO HERE

Place the CLIP model files at:
public/models/Xenova/clip-vit-base-patch32/

The app deliberately sets allowRemoteModels = false. It will not download model
weights at runtime. See the root README.md for the exact model-repository files
and setup instructions. Do not put large model weights into git unless you intend
to store/distribute the roughly 150 MB file with your repository.
